# Movie Recommendation System

A machine learning-based movie recommendation system that combines
Content-Based Filtering, Collaborative Filtering, and Hybrid
Recommendation techniques.

---

## 📌 Project Overview

The Movie Recommendation System recommends movies to users based on
their previous movie ratings and movie characteristics.

The system uses two main recommendation techniques:

1. Content-Based Filtering
2. Collaborative Filtering

These two approaches are combined to create a:

3. Hybrid Recommendation System

The project uses the MovieLens dataset containing movie information
and user ratings.

---

## 🎯 Objectives

The main objectives of this project are:

- Collect movie and user-rating data.
- Preprocess the dataset.
- Perform exploratory data analysis.
- Build a content-based recommendation model.
- Build a collaborative filtering model.
- Combine both models into a hybrid system.
- Generate personalized movie recommendations.
- Evaluate the recommendation system.
- Optimize the recommendation model.
- Handle users with limited rating history.
